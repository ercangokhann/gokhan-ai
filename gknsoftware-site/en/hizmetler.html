Servers and system infrastructure

Installing, configuring and running the servers at the centre of an organisation. We can build from scratch, or take over an existing setup and put it in order.

Windows Server installation
Operating system installation, role configuration, update regime and licensing.
Active Directory / domain
User and computer management, group policy, permissions and password rules. Staff joining and leaving is handled in one place.
File server and permissions
Shared folder structure and department-level access rights — a lasting answer to the question of who can open what.
Virtualisation
Running several servers on one physical machine. Lower hardware cost, easier backup and migration.
NAS and storage
Shared storage setup, RAID configuration, a structure that survives a disk failure.
Server migration
Everything on the old server moved to new hardware — done at the weekend, so that on Monday nobody notices the difference.

Backup and disaster recovery

Taking a backup is half of it; what matters is how quickly you can come back when something goes wrong. We measure that time in advance.

Automated backup setup
Regular, automatic backups of servers, databases and user machines.
On-site and cloud copies
One copy in the building, one outside it. Fire, theft or ransomware will not leave you with a single copy.
Ransomware-resistant backups
Immutable backup copies — even if an attacker gets into the system, your backup cannot be deleted.
Restore drills
Checking that a backup ran is not enough; at set intervals we test whether it actually restores.
Backup verification report
Each month you receive, in writing, which backups ran, how long they took and whether they succeeded.

Firewall, network and endpoint security

Stopping threats at the door, and protecting every device inside. They are two different jobs; we do both.

FortiGate firewall deployment
The organisation's doorway to the internet built on FortiGate: what traffic comes in, what goes out and what gets blocked. Rule design, updates and logging included.
Kaspersky endpoint security
Licensing, deployment and central-console management of the Kaspersky products we are an authorised partner for. The state of every machine on one screen.
VPN and site-to-site links
Secure connections into the company network over FortiGate — from home, a branch or the field: encrypted tunnel, authentication, and a record of who connected when.
Cisco network setup and configuration
Corporate networks built on Cisco switching and wireless access points: VLAN segmentation, cabling, and the guest network kept separate from the company network.
Content and access control
Which sites can be reached and which applications may run — according to the organisation's own rules.
Vulnerability checks
Scanning for externally visible weaknesses and closing them.

Microsoft 365 and office software

It is more than buying licences: choosing the right plan, migrating without loss and then setting the security options correctly is the real work.

Microsoft 365 licensing and setup
Choosing the plan that fits (Business Basic, Standard, Premium), creating users and installing.
E-mail migration
Every mailbox from an old server or another provider moved across without loss, folder structure and calendars included.
Exchange Online configuration
Mail flow, shared mailboxes, distribution lists and signature standards.
Teams, SharePoint and OneDrive
Setting up shared workspaces and organising file sharing permissions.
Multi-factor authentication (MFA)
Making an account unreachable even if the password is stolen. For corporate e-mail this is now the minimum.
Security and compliance settings
Phishing protection, external-sender warnings, data loss rules and session policies.
Other office software
Windows licences, Office installations and the other software the organisation relies on.

E-mail infrastructure and archiving

E-mail is the most critical and most fragile system in most organisations. We keep it running and make it legally retainable.

Mail server setup
On-premise or cloud mail server installation and domain configuration.
E-mail archiving with MailStore
Every message in and out copied to a separate, tamper-proof archive. Even if a user deletes a message it remains in the archive and can be produced as evidence in a dispute.
Search and export from the archive
Correspondence from years ago found in seconds and exported as a file.
SPF, DKIM and DMARC
Correctly configured records that stop others from sending mail in your name — and reduce your own mail landing in recipients' spam folders.
Spam and phishing filtering
Malicious and fraudulent messages filtered out before they reach the user.
Mailbox quotas and hygiene
Keeping mailboxes from swelling, moving old mail into the archive and keeping the server responsive.

Computers, printers and peripherals

Everything on the user's desk: buying it, setting it up, and getting it back on its feet when it fails.

Computer supply and setup
Desktops and laptops configured to requirement, delivered with operating system, applications and user data ready.
Printer and scanner setup
Network printers installed, shared and their drivers deployed; scanners set to send straight to a folder or by e-mail.
Consumables and maintenance
Toner, cartridges and spare parts, plus periodic maintenance.
Uninterruptible power supply (UPS)
Servers and workstations shut down cleanly during a power cut, so no data is lost.
Barcode and labelling systems
Barcode readers and label printers installed and made to work with your existing software.
Data recovery
Recovery attempts from failed disks or deleted files.

Remote support and on-site maintenance

This is the part that makes the difference day to day. Once a system is built, somebody has to keep it running.

Remote support
Connecting to the user's screen and solving the problem there. Most jobs finish in minutes and nobody has to travel.
On-site intervention
Visits for hardware and network problems that cannot be solved remotely.
System monitoring
Continuous monitoring of servers, disks, backups and security status. More often than not we see the fault before you do.
Annual maintenance agreement
A fixed-fee agreement covering a set number of support calls, periodic checks and priority response.
Inventory and documentation
Who has which device, when each licence expires, how the network is wired — written down and kept current.
Onboarding and offboarding
Accounts and machines prepared for new staff; access for leavers closed the same day.

How support works

One number

Whatever the problem, you call one place. Printer, server or e-mail — it makes no difference.

Same-day response

Requests received during working hours get a response the same day. If work has stopped, it does not go into a queue.

Remote first

Most things are solved in minutes over a remote connection. If not, we come out.

Written record

What happened, what was done, when it was closed — all logged, and visible to you at the end of the month.

How we work

No surprises

Most software projects get into trouble not because they run over budget or schedule, but because nobody agreed at the start what would happen. We follow this order.

Listening

We sit down with the person who actually does the job. How is it done today, where does it get stuck, which spreadsheet is filled in by hand — we understand that first. This meeting is free.

A written quote

What will be done, what will not, how long it takes and what it costs — in writing, in front of you. We do not start work on a verbal agreement.

Delivery in pieces

We do not disappear for months and then announce that it is finished. We show working parts early, so that if something is going wrong we can turn back in time.

Migration and go-live

Data from the old system is migrated in full and users are trained. Old and new can run side by side for a while — the way back stays open.

We stay afterwards

Delivery is not the end. When something breaks you reach the person who wrote the software; there is no call centre in between.
